# Sinor Marine — Interactive 3D Maritime Digital Universe

Claude Code handoff package with reference video, project requirements, architecture, configuration data and execution prompts.

## Start
1. Extract the ZIP.
2. Open the extracted folder in Claude Code.
3. Ask Claude: `Read CLAUDE.md and docs/, inspect reference/, validate data/, and execute prompts/01-start.md. Build and test the first working vertical slice.`
4. Claude should initialize the app in this folder and implement the MVP.

The included JSON describes a **representative concept vessel**, not an actual vessel or approved OEM system. The reference video is visual inspiration, not a usable 3D asset. Realistic production geometry requires proper GLB/CAD assets.

## Acceptance
The first release must load a 3D ship, allow orbit/zoom, switch visual modes, select equipment, focus camera, show information, animate a thruster, and return to overview. No inert controls.
