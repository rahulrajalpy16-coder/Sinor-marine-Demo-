# Product requirements
## Audience
Shipowners, superintendents, offshore operations teams, DP engineers, technical buyers, exhibition visitors and trainees.

## Primary journeys
1. Enter cinematic ocean scene -> explore 3D vessel -> select equipment -> inspect -> return.
2. Choose category in equipment tree -> camera flies to equipment -> contextual panel -> activate demonstration.
3. Enter bridge -> approach DP console -> adjust wind/current/heading target -> see illustrative vessel response.
4. Select HPR -> X-ray hull -> view underwater transducer and seabed signal paths.
5. Select thruster -> isolate -> change thrust -> observe propeller rotation and force vector.

## MVP (Phase 1)
Procedural segmented offshore support vessel, 360 orbit/pan/zoom, hybrid materials, blueprint/realistic/X-ray modes, three clickable equipment objects, camera focus, information panel, thruster animation, reset view, mobile touch basics.

## Later phases
Bridge walkthrough, collision-safe interior navigation, DP educational model, HPR simulation, deployment mechanism state machine, guided tours, CMS, multiple vessels.

## Nonfunctional
Accessible controls, responsive panels, loading/error states, asset fallback, performance settings, no proprietary claims, no misleading real-vessel specifications.
