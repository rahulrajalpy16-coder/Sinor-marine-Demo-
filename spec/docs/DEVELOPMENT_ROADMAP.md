# Implementation roadmap
P0: Initialize project, typed schemas, working Canvas and procedural segmented vessel.
P1: Camera orbit/zoom, hybrid PBR+wireframe modes, selectable equipment, inspector and return controls.
P2: Interior bridge and DP console, safe camera transitions, system explorer.
P3: Pure simulation engines for thruster, DP and HPR, UI controls and visual feedback.
P4: X-ray/isolation/exploded assemblies, deployment animation, guided tours.
P5: Optimized GLB replacement pipeline, CMS, multiple vessels, production hosting.

At every stage run typecheck, unit tests, production build and manual browser smoke tests. Never claim phase complete until interactions demonstrably work.
