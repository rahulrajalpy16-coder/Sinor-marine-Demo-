SINOR MARINE - VESSEL SYSTEMS SIMULATOR 1.0.1
"We bring the vessel to you"

Works fully offline. No internet connection is needed or used. Same simulator, same features
and same look as the online version. Built for all-day use at a stand: the screen does not go
to sleep while the simulator is open, the 3D view keeps full speed, and if the page or the
graphics ever crash the simulator restarts itself within a few seconds (a running demo starts
again on its own).

MAC (Apple Silicon: M1, M2, M3, M4, for example MacBook Air M2) - installed once
  1. Copy the folder  Mac  from this pendrive to the Mac (for example to Downloads)
  2. In that folder, Control-click  Install on this Mac.command , choose Open, then Open again
     (if macOS still refuses: System Settings > Privacy & Security > Open Anyway)
  3. It installs "Sinor Marine Simulator" into Applications and starts it
  Afterwards start it from Launchpad or Applications. For a stand: Start Exhibition Demo.command
  Keys: Ctrl+Cmd+F or F11 full screen, Esc close panel / leave demo, Cmd+Q quit.
  Full steps: Mac\READ_ME_MAC.txt

WINDOWS 10 / 11 (64-bit) - runs straight from this pendrive, nothing to install (backup)
  1. Open the folder  Windows
  2. Double-click     Start Sinor Marine Simulator.bat
     (for a stand:    Start Exhibition Demo.bat   - full screen, loops on its own, Esc to leave)
  If Windows shows "Windows protected your PC": click More info, then Run anyway.
  Keys: F11 full screen, Esc close panel / leave demo, Ctrl+Q quit.
  Tip: copy the Windows folder to the laptop's own drive for the fastest start.

TELEVISION
  Connect the laptop to the TV with an HDMI cable. Samsung TVs (Tizen) cannot install this app.
  Android TV / Google TV sets can: Android_TV\INSTALL_ON_ANDROID_TV.txt

FOR A FULL DAY
  Keep the laptop on its charger. Mac: System Settings > Battery > Options, turn on
  "Prevent automatic sleeping on power adapter when the display is off". Windows: Settings >
  System > Power, set Power mode to Best performance.

Anything odd on screen: Simulator button (bottom bar), then Reset all.
