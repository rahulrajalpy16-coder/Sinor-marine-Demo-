SINOR MARINE - VESSEL SYSTEMS SIMULATOR 1.0.0
"We bring the vessel to you"

Works fully offline. No internet connection is needed or used.

WINDOWS 10 / 11 (64-bit) - runs straight from this pendrive, nothing to install
  1. Open the folder  Windows
  2. Double-click     Start Sinor Marine Simulator.bat
     (for a stand:    Start Exhibition Demo.bat   - full screen, loops on its own, Esc to leave)
  If Windows shows "Windows protected your PC": click More info, then Run anyway.
  Keys: F11 full screen, Esc close panel / leave demo, Ctrl+Q quit.

ANDROID TV / GOOGLE TV (Android 7 or newer) - installed once from this pendrive
  1. Plug the pendrive into the TV
  2. With a file manager on the TV, open  Android_TV\SinorMarine-1.0.0.apk
  3. Allow installs from that file manager when asked, then Install
  4. Start "Sinor Marine Simulator" from the TV's apps
  Full steps: Android_TV\INSTALL_ON_ANDROID_TV.txt

Anything odd on screen: Simulator button (bottom bar), then Reset all.
