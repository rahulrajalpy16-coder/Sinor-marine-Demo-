SINOR MARINE SIMULATOR 1.0.1 FOR MAC (Apple Silicon: M1, M2, M3, M4)

What is in this folder
  Sinor Marine Simulator.zip       the app
  Install on this Mac.command      installs the app into Applications and starts it (run once)
  Start Exhibition Demo.command    starts the looping exhibition demo, full screen

Install (once, about one minute)
  1. Keep the three files together in one folder on the Mac (not on the pendrive itself).
  2. Control-click (or right-click)  Install on this Mac.command  and choose Open.
     macOS asks whether to open it: choose Open.
     If macOS only offers "Done" or "Move to Bin": open System Settings > Privacy & Security,
     scroll down, click "Open Anyway" next to the message about the file, then try again.
  3. A Terminal window shows the steps, the app is copied to Applications and it starts.

  Another way, if you prefer: open Terminal, type  bash  and a space, drag
  Install on this Mac.command  into the Terminal window, and press Return.

Why this step is needed
  The app is not registered with Apple (Apple notarisation needs a paid Apple developer account).
  The install file uses only Apple's own built-in tools to unpack the app, remove the
  "downloaded from the internet" flag and sign the app for this Mac only. It downloads nothing
  and sends nothing anywhere.

Daily use
  Start: Launchpad or Applications > Sinor Marine Simulator.
  Exhibition demo: double-click Start Exhibition Demo.command (or press Simulator in the app,
  then Start exhibition demo). Esc or Exit demo leaves the demo.
  Full screen: Ctrl+Cmd+F (or F11). Quit: Cmd+Q. Reload: Cmd+R.
  Saved scenarios and settings stay on this Mac (in your user Library).

For a full day
  Keep the MacBook on its charger, with the lid open or with an external display connected.
  System Settings > Battery > Options: turn on "Prevent automatic sleeping on power adapter
  when the display is off". The simulator itself keeps the screen awake while it is open.
  For a TV: connect it with an HDMI cable (USB-C to HDMI adapter).

If something goes wrong
  "is damaged and can't be opened": run Install on this Mac.command again.
  Black or slow 3D: in the top bar set Quality to medium.
  Anything odd on screen: Simulator button (bottom bar), then Reset all.
